## 3. 研究完成定义

一个文件只有在以下内容齐备时才标记为“已分析”：

- 上游路径和对应版本；
- 主要目的与适用场景；
- 输入、输出和依赖；
- 执行步骤或关键实现；
- 风险、限制和失败路径；
- 对 Codex / 多模型工作台的迁移价值；
- 必要的验证或待确认问题。

仅列出文件名或生成一句摘要，不算完成。
