# 术语表（Skills 中文译文统一用词）

本表是 `translations/skills-zh/` 全部译文的**唯一用词基准**。后续每个批次都必须遵循，以保证 113 篇译文读起来像同一支笔写出来的。

## 一、绝不翻译（硬性红线）

以下内容出现在译文里必须保持英文原样，翻译会导致工具链或运行行为失效。

| 类别 | 示例 | 原因 |
|---|---|---|
| frontmatter `name` | `name: principle-prove-it-works` | 生成器断言 `name` 必须等于文件夹名 |
| 斜杠命令 | `/architect`、`/babysit`、`/poteto-mode` | `check-pstack-docs.mjs` 校验命令真实存在 |
| 工具名与参数 | `Task`、`AskQuestion`、`readonly: true`、`environment: "cloud"`、`run_in_background`、`file_attachments`、`resume` | 宿主按字面量识别 |
| 模型 ID | `claude-opus-5-5-xhigh`、`grok-4.7-xhigh-fast`、`gpt-5-5` | 检查脚本要求与 `setup-pstack` 一致 |
| 文件与目录路径 | `references/design-red-flags.md`、`docs/guide` | 链接解析与磁盘路径 |
| 代码块内容 | 任意 ``` 围栏内的代码、命令、配置 | 可执行性 |
| 配置键名 | `disable-model-invocation`、`subagent_type` | 解析器按字面量读取 |
| 仓库与产品名 | pstack、Cursor、Claude Code、GitHub、Slack | 专有名词 |

> **frontmatter 规则**：`name` 与 `disable-model-invocation` 等键名保留英文；`description` 的**值**可以翻译（它是给人读的说明文字）。

## 五、译文体例

1. **保留原文结构**：标题层级、列表符号、加粗位置与原文一一对应，方便双语对照。
2. **保留 `**Why:**` / `**Pattern:**` 等标签原文**，后面接中文正文。理由：这些标签在上游被当作固定锚点使用。
3. **首次出现**核心术语时写「中文（English）」，之后只用中文。
4. **不增删内容**：译文不添加原文没有的建议，也不省略原文的限定条件。
5. **语气**：与原文一致，用祈使句给指令，不改成「我们应该……」的商量语气。

## 六、待确认项

以下译法建议你确认或替换，确认后回填本表，后续批次统一执行：

- `task` → 「任务」（泛用词，无需保留英文）
- `run` → 「运行」；`autonomous run` → 「自主运行」
- `review` → 「评审」；`reviewer` → 「评审者」
- `verify` → 「验证」；`verifier` → 「验证者」
