# 术语表（Skills 中文译文统一用词）

本表是 `translations/skills-zh/` 全部译文的**唯一用词基准**。

**目标读者是 AI，不是人。** 译文只要求「机器读得准」，不追求中文文采。因此本表的原则是：

- 技术术语、机制名、专有名词**直接留英文**，不做「信达雅」的意译。
- 中文只用来串起句子、表达因果和条件关系。
- 宁可中英混排，也不要为了通顺而改动术语——术语一变，语义就可能漂移。

## 一、绝不翻译（硬性红线）

以下内容翻译会导致工具链或运行行为失效，必须保持英文原样。

| 类别 | 示例 | 原因 |
|---|---|---|
| frontmatter `name` | `name: principle-prove-it-works` | 生成器断言 `name` 必须等于文件夹名 |
| 斜杠命令 | `/architect`、`/babysit`、`/poteto-mode` | `check-pstack-docs.mjs` 校验命令真实存在 |
| 工具名与参数 | `Task`、`AskQuestion`、`readonly: true`、`environment: "cloud"`、`run_in_background`、`file_attachments`、`resume` | 宿主按字面量识别 |
| 模型 ID | `claude-opus-5-5-xhigh`、`grok-4.7-xhigh-fast`、`gpt-5-5` | 检查脚本要求与 `setup-pstack` 一致 |
| 文件与目录路径 | `references/design-red-flags.md`、`docs/guide` | 链接解析与磁盘路径 |
| 代码块内容 | 任意 ``` 围栏内的代码、命令、配置 | 可执行性 |
| 配置键名 | `disable-model-invocation`、`subagent_type` | 解析器按字面量读取 |
| 仓库与产品名 | pstack、Cursor、Claude Code、GitHub、Slack | 专有名词 |

> **frontmatter 规则**：`name` 与 `disable-model-invocation` 等键名保留英文；`description` 的**值**可以翻译。

## 五、译文体例

1. **结构一一对应**：标题层级、列表项数量、加粗位置与原文完全一致，便于机器 diff 和人工双语对照。
2. **固定标签保留英文**：`**Why:**`、`**Pattern:**`、`**Stop:**`、`**The test:**` 等原样保留，只译后面的正文。这些标签在上游被当作锚点。
3. **不增不删**：不添加原文没有的建议，不省略原文的限定条件（如 only when、unless、prefer）。
4. **代码围栏数量与上游一致**：新增或删除代码块都会被校验脚本判为错误。
5. **语气**：原文用祈使句就给祈使句，不改写成「我们应该……」。
