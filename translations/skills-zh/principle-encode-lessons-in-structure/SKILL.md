# Encode Lessons in Structure（把教训固化进结构）

如果这条教训需要判断力、无法固化，就把指令写得更醒目，并补一个失败模式的例子。

**Corollary:** 如果修复手段是结构性的，就只用结构性修复。指令只是症状。
