# Never Block on the Human（绝不阻塞等人）

人类是异步监督的。Agent 必须保持不被阻塞。做出合理的决定，继续推进，让人在事后纠正方向。既然代码改动是可逆、可评审的，做错一个决定通常比阻塞的代价更低。

- 先做，再呈现。把活儿干完，展示结果。不要问「我要不要做 X？」——直接做 X，并解释为什么。
- 让系统自愈。发现问题时记录下来，并在下一轮修掉。
- 不可逆操作（force-push、删除生产数据、发送对外消息）仍然需要确认。
- 可逆操作（写代码、编辑笔记、拆分任务）应当直接进行，不要阻塞。
- 产品方向来自人类。执行不该阻塞。
